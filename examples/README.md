# Code Examples

This directory contains practical code examples for using the AI Chat SDK.

## 📁 Examples

### Basic Integration
- [BasicIntegration.kt](BasicIntegration.kt) - Simplest way to integrate the SDK
- [CustomTheme.kt](CustomTheme.kt) - Using custom Material Theme colors
- [CustomViewModel.kt](CustomViewModel.kt) - Creating a custom ViewModel

### Advanced Usage
- [DirectRepositoryAccess.kt](DirectRepositoryAccess.kt) - Using ChatRepository directly
- [CustomErrorHandling.kt](CustomErrorHandling.kt) - Implementing custom error handling
- [MessageFiltering.kt](MessageFiltering.kt) - Filtering and searching messages

### Configuration
- [ApiKeyConfiguration.kt](ApiKeyConfiguration.kt) - Different ways to configure API keys
- [DatabaseConfiguration.kt](DatabaseConfiguration.kt) - Custom database setup

### UI Customization
- [CustomMessageBubbles.kt](CustomMessageBubbles.kt) - Customizing message appearance
- [CustomLoadingIndicator.kt](CustomLoadingIndicator.kt) - Custom loading animations

## 🚀 How to Use

Each example file contains:
1. Clear explanation of what it demonstrates
2. Complete, runnable code
3. Comments explaining key concepts
4. Related documentation links

Simply copy the relevant code into your project and modify as needed.
